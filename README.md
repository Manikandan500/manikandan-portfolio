# Manikandan K — Portfolio

Personal portfolio site of **Manikandan K** — Computer Science Engineering graduate specialising in Cyber Security & Ethical Hacking, with projects in Deep Learning and Full Stack Blockchain development.

> **Live:** https://manikandan500.github.io/manikandan-portfolio/

## Sections

- **Hero** — availability badge, key stats and an interactive terminal panel
- **About** — background, interests and strengths
- **Skills** — cyber security, security tooling, AI/ML/DL, full stack, programming, systems & cloud
- **Projects** — Real-Time Sign Language Interpretation (Deep Learning) and Fractional Ownership Blockchain Platform
- **Domain Fit** — recruitment domains mapped honestly to actual experience
- **Credentials** — certifications (Infosys Springboard, NPTEL) and education timeline
- **Contact** — email, phone, LinkedIn, resume download and a mailto contact form

## Tech stack

- HTML5, CSS3 (no framework), vanilla JavaScript
- Google Fonts: Inter + JetBrains Mono
- Dark cyber-security theme, fully responsive (980 / 860 / 560 px breakpoints)
- Scroll-reveal via `IntersectionObserver`, `prefers-reduced-motion` supported

## Run locally

```bash
# any static server works
python -m http.server 8000
# then open http://localhost:8000/
```

Or simply open `index.html` in a browser.
